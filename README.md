# homebrew-tap

Personal Homebrew tap for [Ardakilic](https://github.com/Ardakilic)'s tools.

## Formulae

| Formula | Description |
|---|---|
| `lilt` | Cross-platform CLI tool that converts Hi-Res FLAC and ALAC files to 16-bit files at 44.1kHz or 48kHz |

## Installation

```bash
brew tap Ardakilic/tap
brew install lilt
```

## Automatic updates

The `lilt` formula is updated automatically by [lilt's release workflow](https://github.com/Ardakilic/lilt/blob/main/.github/workflows/release.yml) every time a new version is tagged. No manual changes to this repo are needed when lilt releases a new version — the formula's download URLs and SHA-256 checksums are bumped automatically.
